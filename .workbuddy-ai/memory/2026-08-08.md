# 2026-08-08

- Fixed a blank/“nothing showing” wish page caused by a runtime crash: `useReducedMotion()` was used in `WishPage` (added for the reduced-motion flame guard) but was never imported from `framer-motion`. That ReferenceError aborts React render of the whole app. Added `useReducedMotion` to the framer-motion import in `src/App.jsx` and rebuilt. Lesson: `vite build` does NOT catch missing hook imports (they only fail at component render), so a blank page after an edit often means an undefined identifier — grep the edited file for the symbol and check its import. Preview server (vite preview, port 4173) serves the rebuilt dist; just refresh.
